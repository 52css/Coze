# Coze 2.2

本次版本重点增加通用 SSH 内网访问和安全的闲置自动断开。

## 新功能

- 从 `~/.coze/tunnel.json` 动态读取任意数量的内网服务。
- 输入一次 SSH 密码后，通过蓝色按钮连续打开不同服务。
- Coze 重开后可以识别并接管仍在运行的匹配隧道。
- 默认闲置 30 分钟自动断开，可选择 15、30、60 分钟或关闭。
- 网页刷新、跳转、接口请求、点击服务或“续期”都会重新开始倒计时；SSH 保活包不会续期。

## 其他功能

- 微信超过设定阈值后自动生成 DOCX 并放入聊天框。
- Claude Code 与 OpenCode 完成提醒可同时开启。
- 支持限时合盖继续运行。

## 下载

- `Coze-2.2-macOS.zip`：macOS 12 及以上。
- `Coze-2.2-Source.zip`：2.2 完整源码快照。
- `Coze-Windows-WeChatDocx.zip`：Windows 10/11 微信长文本转 DOCX 脚本。

Windows 包目前不包含 SSH 隧道、Claude Code / OpenCode 通知和合盖运行功能。

## 安全说明

- SSH 本地转发仅监听 `127.0.0.1`。
- SSH 密码仅通过匿名管道交给当次认证，不进入环境变量，也不会写入磁盘。
- 仓库与安装包不包含个人服务器地址、用户名或密码。
